# 快速到达账号登录入口

目标是打开切换账号（Change Account）的登录方式列表；无需完成整个新手章节。列表出现立即停止，不继续点游客（Guest）、绑定账号或输入凭据。

## 连接与执行

使用电脑操作工具（cua_repl），按工具文档连接当前运行的游戏。应用标识为 `com.gof.global`，若有副本歧义，使用本轮工具返回的实际运行路径；不要硬编码历史临时 Wrapper 路径。

读取 [实测路径](references/route.md)，先判断当前处于哪一步。若头像已可点击，直接试账号导航；只有入口不可用时才继续必要引导。不要把旧账号交接文件当作新游客状态，也不要顺带做日常任务。

原生游戏通常没有可读按钮的辅助功能树（AX）；根据当前截图识别按钮。脚本不识图、不提供跨分辨率固定坐标回放，由代理确认当前画面后传入坐标。

在已初始化的 `cua_repl` 中加载下列脚本，`SKILL_PATH` 换成当前技能所在绝对路径，`OUTPUT_DIR` 使用当前允许写入的素材目录：

```javascript
var loginModule = await import('SKILL_PATH/scripts/tutorial-session.mjs');
var loginRun = await loginModule.createTutorialSession({
  app: game,
  emitImage: bytes => nodeRepl.emitImage(bytes),
  outputDir: 'OUTPUT_DIR'
});
await loginRun.capture('开始状态');
```

根据本次截图观察到的按钮调用 `await loginRun.clickObserved({label:'实际动作',x:观察到的横坐标,y:观察到的纵坐标})`。该函数点击、刷新 AX、保存并显示后续截图。每次返回后重新判断，不能循环机械推进历史坐标。

- 看到跳过（Skip）即可跳过剧情；强制手指引导优先点指尖所在的控件。
- 过渡动画或黑屏时只补一次观察；不点击猜测位置。按钮出现但手指尚未就位时，提前点击可能无效。
- 普通木材建造可继续；不消耗钻石、不购买加速。遇到资源不足或额外非引导任务，重新检查是否已能打开头像。
- 点任务卷轴图标而非其旁边的任务文字；实测后者在强制引导中无效。
- 窗口被用户移动或修改导致操作失效时，重新获取状态和截图再操作，不自动重放失败动作。

到达登录方式列表后，调用工具要求的 `completion_summary` 结束电脑操作。仅报告已到登录入口，不能声称旧账号已恢复。

## 记录与可移植性

脚本将原始截图和动作日志保存为 PNG 与 `events.jsonl`；日志中的 `attempt` 只表示尝试，实际成功要看后续截图。日志使用 UTC 时间，写中文报告时换算为台北时间（UTC+8）。

此技能实测于 macOS 上运行的游戏应用。手机端可参考相同菜单顺序，但没有实测 Android/iPhone 自动操作，也没有独立手机一键脚本。若没有可操控手机的工具，明确说明边界。

为文章或视频整理素材时保留关键画面和失败原因，区别真实游戏耗时与代理记录耗时；公开前遮挡角色昵称、角色 ID 等账号标识。截图序列不是连续录屏。
