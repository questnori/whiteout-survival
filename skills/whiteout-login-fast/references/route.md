# 2026-11-11 实测路线

环境：macOS 游戏窗口，英文界面，截图为 642×951；下列坐标只供解释历史录像，不作为未来点击依据。游戏版本号未核实。

| 阶段 | 动作 | 成功判据 |
| --- | --- | --- |
| 开场 Bill 对话 | 右上跳过（Skip） | 出现伐木手指 |
| 伐木 | 点手指所指树木 | 人物采集并回营地 |
| 点火 | 点篝火上方火焰图标 | 火焰点燃，进入 Sean 对话 |
| 点火后对话 | Skip | 镜头移动到厨房建造位置 |
| 厨房（Cookhouse） | 点击引导位置，再点建造（Build） | 使用普通木材，显示 2 秒建造；厨房出现 |
| 厨房炉灶（Stove） | 进入厨房，先点左下炉灶家具格，再点 Build | 炉灶 1 级、厨房进度 50% |
| 厨师分配 | 幸存者（Survivors）页 → 绿色加号 | 人数从 0/1 变为 1/1 |
| 用餐和暴风雪 | 每次实际出现 Skip 时点击 | 进入左下点火任务引导 |
| 首次领奖 | 点左下卷轴图标，领取点火（Light a fire）奖励 | 点火任务消失，下一项为厨房奖励 |
| 结束强制引导 | 关闭章节任务面板 | 左上领主头像和资源栏出现 |
| 登录导航 | 头像 → 设置（Settings）→ 账号（Account）→ 切换账号（Change Account） | 出现登录方式列表 |

实测终点提供：游客（Guest）、脸书（Facebook）、谷歌登录（Sign in with Google）、苹果登录（Sign in with Apple）、游戏中心（Game Center）。到此停止，让用户选择原账号对应方式。

实测到达时暖炉 1 级，锯木厂与猎人小屋均未建造，厨房任务奖励尚未领取。证明不必完成第一章才能打开登录入口；未穷举验证是否还能更早进入。

两个容易浪费时间的地方：

1. 厨房打开后立即点 Build 曾无效；引导要求先点炉灶家具格，再点 Build。
2. 任务文字区域点击曾无效；点击卷轴图标才打开章节面板。

初始应用连接还遇到两个同标识应用副本：安装目录实例不能连接，使用工具返回的临时 Wrapper 实例成功。这是本次桌面环境问题，不是游戏通用登录前置。
