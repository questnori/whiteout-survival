## ログインしたいだけなのに、また木を切るところから？

新しい端末にゲームを入れて、自分の街に戻ろうとしたら、始まったのはオープニングとチュートリアル。

Questnori は必要な操作を進め、ストーリーをスキップして、**アカウント切り替え（Change Account）**を開きます。そこから先は、以前のアカウントに連携したログイン方法を選んでください。

### 第1章をすべて終える必要はありません

ここで確認したバージョンでは、最初の調理場のチュートリアルを終え、点火の報酬を受け取ると、プロフィールメニューが使えるようになります。

**プロフィール → 設定（Settings）→ アカウント（Account）→ アカウント切り替え（Change Account）**

すでにプロフィールを開ける場合は、そのまま設定へ。最初の手順は[ルートガイド](skills/whiteout-login-fast/references/route.md)（中国語）にまとめています。

## チュートリアルの操作を任せる

**クイックログイン（Quick Sign-in）スキル**は Codex のコンピューター操作ツールで動作します。現在の画面を確認しながら案内に従い、ログイン方法が表示されたところで停止します。スクリーンショットと操作ログは手元のコンピューターに保存されます。

| Questnori が行うこと | プレイヤーが行うこと |
| --- | --- |
| ストーリーのスキップと必要なチュートリアル操作 | 元のアカウントのログイン方法を選ぶ |
| アカウントメニューを開く | ログインを完了する |
| 操作の記録を残す | アカウントを管理する |

### 使い方

**必要な環境：**macOS で動作するゲームと、コンピューター操作ツール（`cua_repl`）を利用できる Codex。

1. このリポジトリをダウンロードまたはクローンします。
2. `skills/whiteout-login-fast` を `~/.codex/skills/` にコピーします。
3. ゲームを開き、Codex に依頼します。

```text
$whiteout-login-fast を使って最初のチュートリアルを進め、
アカウントのログイン画面で停止してください。
```

[スキルの説明](skills/whiteout-login-fast/SKILL.md) · [操作記録スクリプト](skills/whiteout-login-fast/scripts/tutorial-session.mjs)

## ご利用にあたって

これはデスクトップ向けのスキルで、単独で動作するスマートフォンアプリではありません。現在は macOS のゲーム環境で動作を確認しています。Android・iPhone の自動操作には対応していません。ゲームの更新により、案内やメニューが変わることがあります。

通常のチュートリアル資源のみを使い、課金やダイヤの消費は行わず、ログイン前に停止します。パスワードの再設定やアカウント連携はプレイヤー自身で行ってください。この概要は3言語に対応していますが、詳しいスキルの説明とルートガイドは現在中国語です。

ゲームの配信元とは関係のない独立したプロジェクトです。
